Audit & Control Android Battery Modes in One Place.

Modern Android buries battery optimization toggles across 150 separate screens. Battery Mode Checker consolidates every installed app into a single dashboard with 1-tap live mode switching via rootless Shizuku & Shevery privileged binder IPC.

↓ Download Production APK Add to Obtainium View on GitHub
⚡
Instant Tri-State Auditing
Classifies every package into Unrestricted (Doze exempt), Optimized (Dynamic standby bucketing), or Restricted with zero guesswork.
🎛️
Rootless Mode Switching
Toggle background states with one tap via Shizuku & Shevery reflection-based binder IPC without needing root access.
🛡️
Strict Shizuku Guard Lock
Data and distribution graphs are locked and protected behind an expressive container whenever privileged bridge is offline.
📊
Native Canvas Capsule
Smooth real-time multi-segment distribution bar rendered directly with Compose Canvas and physics-based spring animations.
🔍
Ergonomic Top-Down Search
Borderless 28dp pill search bar positioned directly above category filter chips for seamless thumb navigation.
🔒
100% Offline & Zero Telemetry
Zero internet permissions declared in AndroidManifest.xml. Zero telemetry, zero tracking, and zero background services.
